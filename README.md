# JSOA LP — 一般社団法人訪問販売適正化推進協会

訪問販売事業者向け第三者相談窓口のランディングページ。
Figma「JSOA-LP-Renewal」の **Desktop - FINAL（1440px）** と **Mobile - FINAL（390px）** を実装対象としています。

```

reserve/index.html              個別説明会予約ページ（Jicoo への導線）
privacy/index.html              プライバシーポリシー

assets/images/
  LOGO.png                      ロゴ
  hero-main.jpg                 ヒーロー画像（フォールバック）
  hero-main.webp                同 WebP（PC用・1440w）
  hero-main-sp.webp             同 WebP（SP用・780w）
  jicoo-cover.jpg               Jicoo 予約ページのカバー画像（1040x282）
  reserve-main.jpg              旧・STORES予約のメインイメージ（1200x630／未使用）
```

## CTA（資料請求・お問い合わせ）の遷移先

**`index.html` の先頭にある1行だけ**を書き換えてください。

```html
<script>
  window.JSOA_CTA_URL = 'reserve/index.html';   // ← 遷移先はこの1行だけ
</script>
```

現在は同梱の個別説明会予約ページ（`reserve/index.html`）に向けています。
Jicoo の予約ページへ直接飛ばしたい場合は、ここをその URL に差し替えてください。

ページ内すべての CTA ボタン（ヒーロー / 比較セクション下部 / SP追従バー）と、
ヘッダー・フッターの「お問い合わせ」が一括で切り替わります。
外部ドメインの URL を入れた場合は自動的に別タブで開きます。

空にした場合、ボタンは表示されますがクリックしても遷移しません
（ページ先頭に飛んでしまうのを防いでいます）。

## 個別説明会予約ページ（reserve/index.html）

Jicoo の予約ページへ送り出す前の説明ページです。LP と同じトークン
（Noto Sans JP / 緑のパレット / 角丸）で組んでいます。

**個別説明会の仕様（確定）**

- 実施形式：1社ごとの個別形式（1対1。他社と同席しない）
- 所要時間：45分 ／ オンライン ／ 無料
- 予約システム：Jicoo（ジクー株式会社）
- オンライン会議：Google Meet（予約時に URL を自動発行）

**Jicoo を選んだ理由**

Google カレンダーと双方向に連携し、**担当者の予定が入っている時間を
自動で予約枠から外せる**のが決め手です。同じことを STORES 予約でやると
チームプラン以上（有料）が必要でした（STORES から Google への一方向の
書き出しは無料、逆方向のブロックは有料）。

アカウントは `info@jsoa.net`（協会の Google Workspace）で作成しています。
担当者個人のアカウントで作ると引き継げなくなるためです。空き時間の判定には
このアカウントのカレンダーを使っています。

**Jicoo 側の設定（サイトの記載と揃えること）**

| 項目 | 値 |
|---|---|
| 所要時間 | 45分 |
| 前後のバッファ | 15分 |
| 時間間隔 | 30分 |
| 受付可能枠 | 月〜金 10:00-19:00 |
| 受付可能期間 | 当日から90日間 |
| 受付猶予期間 | 24時間 |
| 同時予約数 | ゲスト1人あたり1件 |
| キャンセル・日程変更 | 前日まで（確定メールのボタンから） |

**開催曜日・時間はサイトに書きません（意図的）**

変更の可能性があるため `reserve/index.html` には書いていません。書くと枠を
変えるたびにサイトも直す必要が出るためです。空き状況は Jicoo のカレンダーが
唯一の情報源、という前提で文面を作っています（「ご都合のよい日時をお選び
ください」など、曜日・時間に依存しない言い方に統一）。

**予約カレンダーの埋め込み**

`reserve/index.html` の `<div class="bookform" id="book-embed">` に、Jicoo の
予約ウィジェットを埋め込んでいます。**Jicoo は無料プランで埋め込みが使えます**
（STORES 予約では有料機能でした）。サイト内で日時選択から入力まで完結します。

```html
<div class="jicoo-widget"
     data-url="https://www.jicoo.com/event_types/-dgOKd6C8EYr/widget"></div>
<script src="https://www.jicoo.com/widget/event_type.js" async></script>
```

コードの取得場所は、Jicoo の**予約ページ ＞ 共有する ＞ ウェブサイトに埋め込む**。
ページを作り直すと `data-url` が変わるので、そのときは取り直してください。

**高さは指定していません。** Jicoo のスクリプトが中身の高さに合わせて div の
`height` をインラインで書き換えるため、CSS で指定しても負けますし、指定する
必要もありません（実機で内側スクロールが出ないことを確認済み）。`reserve.css`
の `.jicoo-widget` にある `min-height:600px` は、読み込み中にレイアウトが飛ぶ
のを防ぐためだけのものです。

Jicoo が出力するコードには `min-width` / `height` / `border` のインライン
style が付いていますが、枠線と角丸をサイトのトークンに揃えるため外しています。

ウィジェットの下に2行置いています。

- `.bookform__privacy` … 個人情報の利用目的とプライバシーポリシーへの導線
- `.bookform__fallback` … 予約ページへの直リンク（スクリプトが読み込めない環境の保険）

**「ご入力いただく項目」セクションは削除しました。** 実際のフォームがページ内に
埋め込まれて役割が重複したためです（マークアップはコミット `241a864` に残って
います）。事前に何を用意すればよいかは「ご予約の流れ」の2番目で伝えています。
プライバシーポリシーへの導線だけは落とせないので、上記のとおり移設しました。

```
https://www.jicoo.com/t/1Y-VENq0-WAB/e/zEO6mR4f
```

> 埋め込みをやめてリンク方式に戻す場合、そのデザイン（`.bookform__link`）は
> コミット `286a491` に残してあります。

**入力項目は Jicoo 側で設定します。**

| 項目 | 種別 | 必須 |
|---|---|---|
| お名前 | 固定項目 | 必須 |
| メールアドレス | 固定項目 | 必須 |
| 会社名 | **追加項目** | 必須 |
| お電話番号 | 追加項目 | 必須 |
| メッセージ | 固定項目 | 任意 |
| 参加者のメールアドレス | 固定項目 | **非表示** |

会社名は固定項目にもありますが、**固定項目の回答は予約確定メールに載りません**。
メールだけでどの会社からの申し込みか分かるようにするため、固定の会社名は
非表示にして、追加項目として作り直しています。同じ理由で電話番号も追加項目です。

固定項目は項目名とタイプを変更できません。プレースホルダーと説明文は設定できるので、
「お名前」に `山田 太郎`、「会社名」に `株式会社〇〇` などの入力例を入れて、
社名と担当者名の取り違えを防いでいます。

ページ内の「ご入力いただく項目」の表示は、Jicoo 側の設定と手で揃えてください。

**Jicoo に上げる画像**

| 画像 | 置き場所 | サイズ |

| `assets/images/jicoo-cover.jpg` | 予約ページのカバー画像 | 1040x282 |

`assets/images/reserve-main.jpg`（1200x630）と `reserve-cover.jpg`（1800x600）は

入れてあるので、必要になったら外してください。

## Figma と意図的に変えている箇所

| 箇所 | Figma | 実装 | 理由 |
|---|---|---|---|
| SPフッターの文字サイズ | 6〜8px | 10px | 6pxは判読が困難なため最小10pxに引き上げ。Figma優先なら戻せます |
| SP「これまで / JSOA加入後」の見出し | 1行 14px | 2行 24px | Figmaはこのセクションだけ他の見出し（24〜26px）より小さく、他と揃えたいとのご要望で変更。SP全体が +48px 高くなります |
| SPヒーローのテキスト | 影なし | 弱い影を追加 | 白文字が写真の明部に重なるとコントラスト比4.5:1を下回るため |
| フッターのロゴ | 白抜き版 | `LOGO-white.png` | 白抜き版の支給がなかったため、`LOGO.png` から生成しました。正式な白ロゴがあれば差し替えてください |
| アイコン全般 | ラスター画像 | インラインSVG | Figmaの書き出しPNGを画素単位でトレースしてSVG化。元アイコンのSVGがあれば差し替えてください |
| カード・パネルの角丸 | 0 | `--radius` | 角丸ありのほうが良いとのご判断で現状維持 |
| ヘッダー・フッターの「FAQ」 | あり | 削除 | 中身が未定で、押しても何も起きないリンクになっていたため。FAQ の役割は個別説明会が担う判断。必要になれば戻せます |
| フッターの著作権表記 | `@2026 JSOA` | `© 2026 JSOA` | `@` は著作権記号ではないため。Figma の誤記と判断してご確認のうえ修正 |

## 画像について

グラフと「これまで / JSOA加入後」の比較図は、Figma では画像でしたが
**すべて HTML/CSS で再現**しています（`design/reference/` の4点は参照用）。
合計 9.6MB の画像がマークアップに置き換わり、文字の選択・検索・読み上げが可能です。

ヒーロー画像は WebP を第一候補、元の JPEG をフォールバックとする `<picture>` 構成です
（1.31MB → 70KB / SP は 29KB）。
