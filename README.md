# JSOA LP — 一般社団法人訪問販売適正化推進協会

訪問販売事業者向け第三者相談窓口のランディングページ。
Figma「JSOA-LP-Renewal」の **Desktop - FINAL（1440px）** と **Mobile - FINAL（390px）** を実装対象としています。

## ファイル構成

```
index.html                      LP本体（SVGアイコンはスプライトとして先頭に内包）
reserve/index.html              個別説明会予約ページ（STORES 予約への導線）
privacy/index.html              プライバシーポリシー
assets/css/style.css            LPのスタイル（モバイルファースト、768px で PC レイアウトへ）
assets/css/reserve.css          下層ページ（reserve / privacy）のスタイル
assets/js/main.js               CTAリンクの一括適用 / SP 追従CTA
assets/images/
  LOGO.png                      ロゴ
  hero-main.jpg                 ヒーロー画像（フォールバック）
  hero-main.webp                同 WebP（PC用・1440w）
  hero-main-sp.webp             同 WebP（SP用・780w）
  reserve-main.jpg              STORES予約のメインイメージ（1200x630）
  reserve-cover.jpg             STORES予約のサイトカバー画像（1800x600）
design/reference/               Figma から書き出したデザイン参照用画像（実装には使用しない）
design/banner/                  STORES予約に上げる画像の版下（下記参照）
```

ビルド工程はありません。`index.html` をそのままブラウザで開けば動作します。

## CTA（資料請求・お問い合わせ）の遷移先

**`index.html` の先頭にある1行だけ**を書き換えてください。

```html
<script>
  window.JSOA_CTA_URL = 'reserve/index.html';   // ← 遷移先はこの1行だけ
</script>
```

現在は同梱の個別説明会予約ページ（`reserve/index.html`）に向けています。
STORES 予約のページへ直接飛ばしたい場合は、ここをその URL に差し替えてください。

ページ内すべての CTA ボタン（ヒーロー / 比較セクション下部 / SP追従バー）と、
ヘッダー・フッターの「お問い合わせ」が一括で切り替わります。
外部ドメインの URL を入れた場合は自動的に別タブで開きます。

空にした場合、ボタンは表示されますがクリックしても遷移しません
（ページ先頭に飛んでしまうのを防いでいます）。

## 個別説明会予約ページ（reserve/index.html）

STORES 予約へ送り出す前の説明ページです。LP と同じトークン
（Noto Sans JP / 緑のパレット / 角丸）で組んでいます。

**個別説明会の仕様（確定）**

- 実施形式：1社ごとの個別形式（1対1。他社と同席しない）
- 所要時間：45分 ／ オンライン ／ 無料
- 予約システム：STORES 予約（フリープラン）
- 定員：1名（STORES 側で設定済み）

**開催曜日・時間はサイトに書きません（意図的）**

STORES 側は 月・水・金 の 10:00 / 12:00 / 14:00 / 16:00 で枠を作っていますが、
変更の可能性があるため `reserve/index.html` には書いていません。書くと枠を
変えるたびにサイトも直す必要が出るためです。空き状況は STORES のカレンダーが
唯一の情報源、という前提で文面を作っています（「ご都合のよい日時をお選び
ください」など、曜日・時間に依存しない言い方に統一）。

なお枠数は水曜が5回ある月に月52枠となり、フリープランの上限50をわずかに
超えます。月末の枠が公開ページに出ているか、ときどき確認してください。

**予約カレンダーへの導線（STORES 予約へのリンク）**

`reserve/index.html` の `<div class="bookform" id="book-embed">` に、
STORES 予約へ移動するボタンを置いています。遷移先は、その中の
`.bookform__btn` の `href` **1か所だけ**です。

```
https://jsoa.stores.jp/reserve/jsoa/1977464
```

末尾の数字は STORES 予約のメニューID（JSOA個別説明会）です。この
**メニュー個別URL**に飛ばすと「予約」タブに直接着地します。
`/reserve/jsoa` だけだと「詳細」タブに着地してクリックが1回増えます。

> **カレンダー画面そのものには直接着地できません**
> - `/reserve/jsoa/widget/calendar` は「すべての予約ページ」ドロップダウン付きの
>   管理画面風の素のカレンダーで、顧客向けの画面ではありません。
> - カレンダーを iframe でページ内に表示する方法は STORES 予約の**有料機能**です
>   （管理画面の該当タブに「有料機能お試し中」の表示があります）。トライアルが
>   終わると表示されなくなるため、無料で運用できるリンク方式にしています。
>   iframe 版の実装はコミット `b0f07ae` に、戻す場合の高さ指定（PC 620px /
>   SP 560px）は `reserve.css` の `.bookform iframe` に残してあります。

STORES 側でメニューを作り直すとIDが変わります。そのときは管理画面の
「予約」タブでURLを取り直して、この `href` を差し替えてください。
ボタンは別タブで開きます（`target="_blank"`）。

**入力項目は STORES 予約側で設定します。**
会社名はアンケート機能で追加しています（フリープランはアンケート1問まで）。
ご担当者名・メールアドレス・電話番号は標準のお客様情報でまかなえます。
ページ内の「ご入力いただく項目」の表示は、STORES 予約側の設定と手で揃えてください。

**STORES 予約に上げる画像は2枚あり、設定場所が違います**

| 画像 | 置き場所 | サイズ |
|---|---|---|
| `assets/images/reserve-main.jpg` | 予約ページごとの「メインイメージ設定」 | 1200x630 |
| `assets/images/reserve-cover.jpg` | サイト全体のカバー画像（詳細タブの最上部） | 1800x600 |

どちらも LP の PC ヒーローと同じ構成（左にグリーンの面、右に同じ写真）にして、
LP から遷移してきた人が同じサイトだと分かるようにしています。

カバー画像には文字を入れていません。STORES が左下に協会名を白文字で重ねるためで、
その帯は無地のグリーン（#14512a／白文字とのコントラスト比 9.4:1）にしてあります。

作り直すときは版下 `design/banner/reserve-main.html` / `reserve-cover.html` を編集し、
Playwright でそれぞれのサイズのスクリーンショットを撮り直してください。

LP と違い、このページはヘッダーを SP でも表示します（検索や直リンクで
このページに直接来る人がいるため）。`<meta name="robots" content="noindex">` を
入れてあるので、必要になったら外してください。

## プライバシーポリシー（privacy/index.html）

個別説明会の申し込みで会社名・ご担当者名・電話番号・メールアドレスを取得するため、
当協会名義のポリシーを LP 側に置いています。STORES 予約の
「プライバシーポリシー」設定は無料プランだと自前のページに向けられず、
また既定の文面は STORES 社のものなので、当協会の取り扱いは書かれていません。

記載内容は特商法表示の事業者情報（所在地・代表者・連絡先）と揃えてあります。
**制定日が未記入です**（`<!-- TODO -->` あり）。公開前に日付を入れてください。

内容は一般的な構成にもとづく草案です。法務の確認を受けたうえで公開してください。

## Figma と意図的に変えている箇所

| 箇所 | Figma | 実装 | 理由 |
|---|---|---|---|
| SPフッターの文字サイズ | 6〜8px | 10px | 6pxは判読が困難なため最小10pxに引き上げ。Figma優先なら戻せます |
| SP「これまで / JSOA加入後」の見出し | 1行 14px | 2行 24px | Figmaはこのセクションだけ他の見出し（24〜26px）より小さく、他と揃えたいとのご要望で変更。SP全体が +48px 高くなります |
| SPヒーローのテキスト | 影なし | 弱い影を追加 | 白文字が写真の明部に重なるとコントラスト比4.5:1を下回るため |
| フッターのロゴ | 白抜き版 | `LOGO-white.png` | 白抜き版の支給がなかったため、`LOGO.png` から生成しました。正式な白ロゴがあれば差し替えてください |
| アイコン全般 | ラスター画像 | インラインSVG | Figmaの書き出しPNGを画素単位でトレースしてSVG化。元アイコンのSVGがあれば差し替えてください |
| カード・パネルの角丸 | 0 | `--radius` | 角丸ありのほうが良いとのご判断で現状維持 |
| ヘッダー・フッターの「FAQ」 | あり | 削除 | 中身が未定で、押しても何も起きないリンクになっていたため。FAQ の役割は個別説明会が担う判断。必要になれば戻せます |
| フッターの著作権表記 | `@2026 JSOA` | `© 2026 JSOA` | `@` は著作権記号ではないため。Figma の誤記と判断してご確認のうえ修正 |

## 画像について

グラフと「これまで / JSOA加入後」の比較図は、Figma では画像でしたが
**すべて HTML/CSS で再現**しています（`design/reference/` の4点は参照用）。
合計 9.6MB の画像がマークアップに置き換わり、文字の選択・検索・読み上げが可能です。

ヒーロー画像は WebP を第一候補、元の JPEG をフォールバックとする `<picture>` 構成です
（1.31MB → 70KB / SP は 29KB）。
