## P7　その一本が、時間を奪う

**見るサイト**

| | URL |
|---|---|
| 消費者庁「特定商取引法ガイド」執行状況 | https://www.no-trouble.caa.go.jp/action/ |
| 内閣府 消費者委員会「消費者行政における執行力の充実に関する提言」（平成29年8月） | https://www.cao.go.jp/consumer/iinkaikouhyou/2017/20170829_teigen.html |

**確認する内容**

| 資料の記述 | 状態 |
|---|---|
| 引用「特商法における行政執行は、一般に、PIO-NETに蓄積されている消費生活相談情報や消費者等からの申出等を端緒として調査を開始し…行政処分と事業者名の公表を行う」 | ［済］ |
| 処分件数 81／94／132／116／80（2021〜2025年度） | ［済］クライアントが執行状況ページで確認 |
| 5年で503件 | ［済］上記の合計 |
| どの年度にも代表取締役個人への業務禁止命令が含まれている | ［済］執行状況ページの各年度で確認 |
| 「処分に至らない段階でも、相談が集まったというだけで事業者が呼ばれる」 | 運営会社周辺の実例。**行政の運用方針としては断定していない** |

### この件数の扱いについて（重要）

- **件数は増えていません。** 2023年度（132件）がピークで、2025年度（80件）は5年で最少です。
  **「処分が増えている」とは書かないでください。**
- 各年度ページの**検索結果件数**です。法人への業務停止命令・指示と、役員個人への
  業務禁止命令が**別々の行**として数えられています。「処分を受けた事業者の数」ではありません。
- グラフでは特定の年度を強調していません。件数に傾向がないためです。
